# BondInWater Website

A client-facing website presentation for BondInWater, showcasing living ecosystems, architectural masterplanning, oceanariums, vivariums, and nature biotope engineering.

## Tech Stack

- **Framework**: Vite + React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Motion & Interaction**: Framer Motion
- **Package Manager**: npm

## Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

## Getting Started

### 1. Installation

Install project dependencies using the existing lockfile:

```bash
npm install
```

### 2. Development

Start the local Vite development server:

```bash
npm run dev
```

The application will be available at `http://localhost:3000/`.

### 3. Production Build

Compile TypeScript and build the production bundle:

```bash
npm run build
```

The production output will be generated in the `dist/` directory.

### 4. Preview Build

Preview the production build locally:

```bash
npm run preview
```

## Environment Configuration

No external environment variables are required to run this client demonstration locally. If environment variables are introduced in future integrations, refer to `.env.example` for the required configuration keys.
