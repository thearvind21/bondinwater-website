## 🌊 Overview

**BondInWater** is an end-to-end design, engineering, and turnkey execution studio specializing in large-scale aquatic architectures, bio-authentic wildlife habitats, public oceanariums, and custom acrylic installations. 

Rather than a standard aquarium contractor, BondInWater operates across the full project lifecycle — **Design → Build → Operate & Maintain** — delivering biological integrity, precision engineering, and museum-grade visual aesthetics.

### Multidisciplinary Divisions

The website showcases BondInWater's 9 core capability divisions:

1. **Division A: Conceptualisation & Architectural Planning**  
   Feasibility assessments, spatial programming, ecological viability studies, and immersive architectural planning for private and commercial spaces.
2. **Division B: Zoo & Habitat Masterplanning**  
   Ethological enclosure architecture, visitor journey circulation, safety barriers, and behavioral enrichment zones meeting international zoological standards.
3. **Division C: MEP, Life Support Systems (LSS) & HVAC Engineering**  
   Biochemical filtration, ozone sterilization, protein fractionation, thermodynamic climate control, and water chemistry automation.
4. **Division D: 3D Visualisation & Architectural Walkthroughs**  
   Photorealistic CGI rendering, virtual reality walkthroughs, structural modeling, and lighting simulations prior to site mobilization.
5. **Division E: Turnkey Project Execution & Site Management**  
   Single-source general contracting, on-site structural engineering, MEP coordination, water-tight testing, and commissioning.
6. **Division F: Custom Aquariums & Oceanariums**  
   Freshwater biotope aquascapes, marine reef systems, walk-under underwater acrylic tunnels, and 360-degree cylindrical panoramic tanks.
7. **Division G: Precision Acrylic Fabrication & Swimming Pools**  
   Thermoformed optical-grade acrylic panels (20mm to 300mm+), cantilevered transparent swimming pool walls, and underwater viewing ports with 20-year UV warranties.
8. **Division H: Bioactive Terrariums, Paludariums & Vivariums**  
   Living rainforest walls, misted ripariums, desert vivariums, automated climate controls, and micro-fauna bio-active substrates.
9. **Division I: Lifelong Operations, Maintenance & Biological Stewardship**  
   Laboratory-grade water analysis, preventive LSS servicing, emergency biological intervention, and dietetics management by certified marine biologists.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: `>= 18.17.0` (Recommended: Node 20 LTS or later)
- **npm**: `>= 9.0.0` (or `pnpm` / `yarn`)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/thearvind21/bondinwater-website.git
   cd bondinwater-website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server with Turbopack:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Building for Production

Compile and optimize the website for production:

```bash
npm run build
```

Run the production server locally:

```bash
npm run start
```
